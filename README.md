🛡️ Raksha – Security Monitoring & Incident Awareness Platform
🧠 Project Overview

Raksha is a security-focused web application designed to demonstrate core security concepts such as authentication, session handling, and incident awareness in a simplified and educational manner.

The project simulates how real-world systems detect, log, and display security-related events, helping users understand how authentication failures, suspicious activities, and basic threat indicators are handled in practice.

Raksha was built with a strong emphasis on security fundamentals, clean backend logic, and safe session handling.

🔄 Project Workflow (How It Works)

User Authentication
Users log in with credentials verified using secure hashing.

Session Management
Authenticated users are tracked using secure server-side sessions.

Incident Simulation
Security-related events such as failed logins or suspicious behavior are logged.

Dashboard Display
Logged incidents are displayed to help users understand security flow.
